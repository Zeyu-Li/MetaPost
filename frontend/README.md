# MetaPost frontend

React app built with [Vite](https://vite.dev/). Requires Node.js 22.12 or newer and Yarn 1.

## Available Scripts

In the project directory, you can run:

### `yarn start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).
The page reloads when you make edits.

### `yarn test`

Runs the tests once with [Vitest](https://vitest.dev/).

### `yarn build`

Builds the app for production into the `build` folder.

### `yarn preview`

Serves the production build locally at [http://localhost:3000](http://localhost:3000).
